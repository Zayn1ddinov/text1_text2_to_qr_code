# QR-коды с надписью

Скрипт генерирует PNG с QR-кодом серийного номера и надписью под ним (библиотеки `qrcode` и `Pillow`).

## Установка

```bash
git clone https://github.com/Zayn1ddinov/text1_text2_to_qr_code
cd text1_text2_to_qr_code
pip install -r requirements.txt
```

## Подготовка данных

Создайте CSV или Excel-файл (`.xlsx`) с двумя колонками:

| серийный номер  | надпись   |
|-----------------|-----------|
| 901SF2NDKB00164 | HSC010017 |

- 1-я колонка — что зашифровать в QR-коде, 2-я — надпись под кодом.
- Строка заголовка необязательна.
- CSV можно сохранить из Excel через `;` или `,` — разделитель определяется сам.
- Если надпись пустая, под кодом будет «Надпись отсутствует».

Пример — файл `data.csv`.

## Запуск

```bash
python main.py                       # берёт data.csv
python main.py партия.xlsx           # свой файл
python main.py data.csv -o папка --font-size 40 --font /путь/к/шрифту.ttf
```

Картинки сохраняются в папку `qrcodes_with_text` (или в указанную через `-o`) с именами `QR_<серийный номер>.png`.

## Шрифт

По умолчанию используется Arial (macOS, Windows) или DejaVu Sans (Linux) — оба с кириллицей.
Другой шрифт можно указать через `--font`.
